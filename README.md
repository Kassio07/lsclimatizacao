# LS Climatização Profissional

Landing page institucional e comercial da **LS Climatização Profissional — Assistência Técnica Lima Santos**, com atendimento em Brasília, Samambaia, Águas Claras e região.

O site apresenta serviços de climatização, assistência técnica para eletrodomésticos e serviços elétricos, conduzindo o visitante ao contato direto pelo WhatsApp.

## Demonstração

Produção: [https://ls-climatizacao.vercel.app/](https://ls-climatizacao.vercel.app/)

## Tecnologias

- HTML5 semântico
- CSS3 com Custom Properties
- JavaScript puro
- JSON-LD com dados estruturados de negócio local
- Integração com WhatsApp e Instagram

O projeto não utiliza frameworks ou bibliotecas JavaScript externas.

## Funcionalidades

- Layout responsivo para celular, tablet e desktop
- Menu de navegação mobile
- Carrossel de serviços no Hero
- Botões com mensagens personalizadas para o WhatsApp
- Comparador interativo de antes e depois
- Faixa animada de marcas atendidas
- Incorporação de vídeo do Instagram
- Animações ativadas durante a rolagem
- Suporte a `prefers-reduced-motion`
- Botão flutuante do WhatsApp
- Atualização automática do ano no rodapé
- Navegação por teclado e estilos de foco

## SEO

A landing page inclui:

- Title e meta description

- Open Graph
- Twitter Card
- Sitemap XML
- Robots.txt
- Dados estruturados `LocalBusiness`
- SEO local para Brasília e região

## Executando localmente

Por ser um projeto estático, é possível abrir o arquivo `index.html` diretamente no navegador.

Para uma visualização mais próxima do ambiente de produção, utilize um servidor local, como a extensão **Live Server** do Visual Studio Code.

## Publicação

O projeto pode ser publicado em qualquer serviço compatível com sites estáticos, como:

- Vercel
- Netlify
- GitHub Pages
- Hospedagem compartilhada

O arquivo de entrada é o `index.html` e não existe etapa de build.

## Manutenção

Os principais arquivos para manutenção são:

- `index.html`: conteúdo, SEO, seções e dados da empresa
- `css/style.css`: identidade visual, layout e responsividade
- `js/script.js`: WhatsApp, menu, carrossel, comparador e animações
- `assets/images/`: fotografias utilizadas na página
- `robots.txt` e `sitemap.xml`: configurações de rastreamento

Ao alterar telefone, domínio, endereço, horário ou regiões atendidas, revise também o JSON-LD, os links de contato, o rodapé, o sitemap e o robots.txt.

## Imagens e marcas
