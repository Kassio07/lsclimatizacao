# Logos da faixa de marcas

SVGs locais obtidos da biblioteca Simple Icons via jsDelivr:

- `lg.svg`
- `samsung.svg`
- `fujitsu.svg`
- `consul.svg`

As marcas Elgin, Gree, Daikin, Springer Midea, Carrier e Electrolux utilizam temporariamente wordmarks tipográficos no HTML. Eles devem ser substituídos por assets oficiais quando houver arquivos aprovados para uso.

Todas as marcas aparecem apenas como referência de equipamentos atendidos, sem indicar autorização, credenciamento, parceria ou representação oficial.
